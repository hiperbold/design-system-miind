# Design System MIIND

Referência visual da MIIND: cores, tipografia, componentes e aplicações para social media.

- `index.html`: design system com biblioteca filtrável.
- `social-media/png/`: seis exemplos de anúncios e quatro posts em PNG 1440×1800.
- `social-media/miind-criativos-feed-editavel.html`: composições HTML/CSS editáveis.
- `social-media/catalogo-criativos.json`: textos e IDs dos exemplos.

Site estático, sem build, backend, cookies ou coleta de dados. A publicação usa GitHub Pages, branch main, diretório raiz.

As artes são exemplos para revisão. Não constituem anúncios aprovados ou campanhas em veiculação.
