# Design System MIIND

Projeto estático de referência visual da marca.

## Estrutura e edição
- Fonte pública: index.html. Fontes e prévias incorporadas para leitura offline.
- Exemplos editáveis: social-media/miind-criativos-feed-editavel.html.
- PNGs: social-media/png. Catálogo textual: social-media/catalogo-criativos.json.
- O catálogo não gera automaticamente o HTML nem os PNGs. Manter as três representações consistentes.
- Pacote para download: social-media/miind-exemplos-feed.zip. Regenerar após alterar arquivos.

## Publicação e privacidade
- GitHub Pages usa main, raiz, com .nojekyll. Nenhum build necessário.
- Não incluir documentos internos, planejamento comercial, notas de aprovação, credenciais, caminhos locais ou links privados nos arquivos públicos nem no ZIP.
- Não adicionar analytics ou formulários sem solicitação.
- Alterações futuras: validar localmente; commit, push e publicação apenas mediante pedido.

## Identidade e verificação
- Azul institucional #1d3cab. Sora nos títulos, Manrope no corpo e JetBrains Mono nas etiquetas.
- Preservar desenho vetorial, proporções e ponto final do logo.
- Exemplos de feed usam base 1080x1350 e PNG 1440x1800.
- Verificar desktop e mobile, carregamento das fontes, filtros, links de download, dimensões dos PNGs e integridade do ZIP.
- Usar linguagem clara em português, sem travessão.
- Registrar contexto neste AGENTS.md; CLAUDE.md contém apenas @AGENTS.md.
